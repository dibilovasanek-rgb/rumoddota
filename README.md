# [ModdotaRU](https://moddota.com)

Проект русскоязычной документации ModdotaRU на GitHub Pages.

Сайт создан с помощью [VitePress](https://vitepress.dev/) — современного генератора статических сайтов.

### Установка

```bash
$ npm install
```

### Локальная разработка

```bash
$ npm run dev
```

Эта команда запускает локальный сервер разработки. Большинство изменений отображается сразу, без перезапуска сервера.

### Сборка

```bash
$ npm run build
```
