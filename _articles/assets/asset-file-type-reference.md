чник по типам файлов активов

Этот список содержит всю информацию о типах активов, а также связанные с ними инструменты и руководства, объясняющие форматы.

| Тип | .Расширение | Эквивалент S1 | Информация, формат, декомпилятор |
| ------------------ | ---------- | ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Анимация | `vanim` | `smd` | Файлы `.smd` добавляются в `.vmdl` через редактор моделей для создания файлов `.vanim`.                                                                                                                      |
| Анимационная последовательность | `vgarp` | ?                 | ??                                                                                                                                                                                                        |
| Карта | `vmap` | `vmf` | Hammer Files.<br />Декомпилятор пока не известен людям, но ходят слухи, что над ним работает волшебный пингвин.                                                                                          |
| Материал | `vmat` | `vmt` | Сделано с использованием файлов `.tga` в редакторе материалов. <br /> Декомпилятор: [S2V](https://s2v.app/) |
| Модель | `vmdl` | `mdl` | Руководство по декомпиляции: [MDL to VMDL Conversion](models/mdl-to-vmdl-conversion) |
| сетка | `vmesh` | `smd`,`dmx`,`fbx` | Определяет форму модели. <br /> Загружается в редактор моделей для создания новой модели.                                                                                                                        |
| Частица | `vpcf` | `pcf` | Декомпилятор: [S2V](https://s2v.app/)<br /> Пока не известен метод преобразования PCF в VPCF.                                                                                                                  |
| Звук | `vsnd` | `wav` | Берет файлы `wav`/`mp3` и преобразует их в этот файл с помощью `.vsndevts` |
| Звуковое событие | `vsndevts` | `txt` | [Sound Editor](https://github.com/pingzing/dota2-sound-editor) считывает строки Source 1, которые идентичны строкам, используемым в Source 2. <br />Guide: [Adding and playing Custom Sounds](custom-sounds) |
| Текстура | `vtex` | `vtx` | Скомпилировано из файлов `.tga`. <br />Руководство: [Extracting and Compiling VTEX files](/assets/extracting-and-compiling-vtex-files) |

Большинство форматов Source 2 можно декомпилировать с помощью [Source 2 Viewer](https://s2v.app/).

Он будет обновляться по мере того, как мы будем получать больше знаний и создавать больше инструментов для декомпиляции и преобразования файлов.
