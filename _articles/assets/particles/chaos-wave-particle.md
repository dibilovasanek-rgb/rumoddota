<h1>Часть четвертая: Доработка системы</h1>
<p>Наша система почти закончена. Теперь мы собираемся добавить несколько слоев волны.</p>
- Откройте свою волновую частицу.
<br />
- Уберите детей.
<br />
- Сохраните как новую частицу для внешнего слоя (у него не должно быть дочерних элементов).
<br /> — снова сохраните как новую частицу для контура (у нее также не должно быть дочерних элементов).
<p>Эти три слоя будут вести себя одинаково, между каждым слоем есть только три различия.</p>
1. Радиус
<br />
2. Цвет
<br />
3. Порядковый номер
<p>Давайте установим наши 3 слоя (или больше, если хотите) следующим образом. </p>
<p>
  Для самого внутреннего слоя, нашего основного слоя, отрегулируйте цвет, чтобы он стал очень ярким,
<b>конечный масштаб радиуса </b> в <b>Масштаб радиуса </b> равен 0,6, а для <b>sequence min/max</b> установлены значения 7 и 8.
</p>
<p>
  Для внешнего слоя, второго слоя, отрегулируйте цвет между очень ярким цветом и черным.
  иметь конечный масштаб <b>radius</b> в <b>Масштаб радиуса </b> как 1,0, а для <b>sequence min/max</b> установлено значение 7
  и 8.
</p>
<p>
  Для слоя контура, последнего слоя, настройте цвет на черный и установите конечный масштаб радиуса <b></b>.
  в <b>Масштаб радиуса </b> равен 1,2.
</p>
<p>
Теперь мы объединяем два внешних слоя в наш основной слой, добавляя дочерние элементы. Ваш экран должен выглядеть
  вот так.
</p>
<img src="/images/external/ymA3yUU.png"></img>
<p>
  Если у вас нет частиц земли, на этом пора закончить. Однако, если у вас есть заземление
  частица тогда:
</p>
- Создать новую частицу.
<br />
- Добавить частицу земли в качестве дочернего элемента.
<br /> — добавить волновую частицу как дочернюю.
<p>
  Важно, чтобы наземная частица находилась над волновой частицей. Это порядок, в котором ваш
  Частица будет визуализирована. Если наземная частица находится ниже волновой частицы, она будет сверху волны.
  частица, а это не то, чего мы хотим.
</p>
<h1>Реализовать в игре</h1>
<p>
  Теперь, когда частица готова, нам нужно использовать ее в игре. Обратите внимание, что эта частица не
  полностью совместим со снарядом. Поэтому имитируем снаряд следующим образом:
</p>
<h4>KV npc_abilities_custom.txt</h4>
<p>В способности, которую вы хотите использовать, вставьте эти строки.</p>

```
"precache"
{
    "particle"		"particles/custom/tutorial/cyclone.vpcf"
}
```
<p>Теперь, когда вы хотите запустить частицы в Lua, вы делаете следующее</p>
```
lua
local info = {
    ...
    EffectName = "",
    vVelocity = keys.caster:GetForwardVector() * ProjectileSpeed,
    fDistance = Distance,
    fStartRadius = Radius,
    fEndRadius = Radius,
    ...
}

local projectile = ProjectileManager:CreateLinearProjectile(info)

-- Create particle
local tornadoFxIndex = ParticleManager:CreateParticle( "particles/custom/tutorial/cyclone.vpcf", PATTACH_CUSTOMORIGIN, caster )
ParticleManager:SetParticleControl( tornadoFxIndex, 0, keys.caster:GetAbsOrigin() )
ParticleManager:SetParticleControl( tornadoFxIndex, 1, keys.caster:GetForwardVector() * ProjectileSpeed )
ParticleManager:SetParticleControl( tornadoFxIndex, 2, Vector( Radius, 0, 0 ) )
ParticleManager:SetParticleControl( tornadoFxIndex, 3, Vector( Distance / ProjectileSpeed, 0, 0 ) )

Timers:CreateTimer( 6.0, function()
        ParticleManager:DestroyParticle( tornadoFxIndex, false )
        ParticleManager:ReleaseParticleIndex( tornadoFxIndex )
        return nil
    end
)
```
<p>Когда это реализовано, ваши частицы теперь должны появиться в игре.</p>
<p>На этом завершается мой урок по созданию частиц Волны Хаоса.</p>
