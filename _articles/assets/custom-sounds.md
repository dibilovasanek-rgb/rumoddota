вательские звуки

Вот пошаговое руководство по настройке звуковых событий.

## Шаг 1. Подготовка файла

Вам нужен файл с расширением `.mp3`, `.wav` может подойти, но я не пробовал. Конвертировать звуки в `.mp3` можно любым приличным звуковым редактором, я использую Audacity, скачать можно с [here](https://audacity.sourceforge.net/download/).

Если вам нужен звук из видео на YouTube, я рекомендую использовать этот сайт: https://www.vidtomp3.com/

## Шаг 2. Скопируйте/переместите файл в папку с содержимым.
Звуковые файлы, которые будут скомпилированы с помощью Source2 dota, должны быть помещены в папку **content\dota_addons\ADDON_NAME\sounds**. Если у вас его нет, создайте его.

## Шаг 3. Событие Valve Custom Sounds

Также внутри папки содержимого вашего аддона должна быть папка soundevents:

![img](/images/external/guI3k-1c84b64257.png)
Создайте его, если его нет. Здесь расположены текстовые файлы с расширением **`.vsndevts`**. Вы можете назвать его как хотите, пока сохраняете это расширение. Я обычно использую `custom_sounds.vsndevts` для всех звуков аддона и **обязательно предварительно кеширую этот файл где-нибудь** (обычно проще сделать это один раз в Lua Precache(context) и забыть об этом).

Структура файла довольно проста: это список KV с именем звуковой строки в качестве первого значения каждого звукового блока, а затем множество значений, управляющих различными свойствами звуков, которые в большинстве случаев не так важны, если вы используете этот код:
```
"SoundStringName"
{
    "operator_stacks"
    {
        "update_stack"
        {
            "reference_operator"
            {
                "operator"              "sos_reference_stack"
                "reference_stack"       "dota_src1_3d"
                "operator_variables"
                {
                    "vsnd_files"
                    {
                        "value"
                        {
                              "value0"        "sounds/FileName.vsnd"
                        }
                    }
                    "volume"            {   "value"     "10.00000"  }
                    "pitch_rand_min"    {   "value"     "-0.05000"  }
                    "pitch_rand_max"    {   "value"     "0.050000"  }
                    "pitch"             {   "value"     "1.000000"  }
                    "soundlevel"        {   "value"     "100.00000" }
                    "distance_max"      {   "value"     "1600.000"  }
                    "event_type"        {   "value"     "1.000000"  }
                }
            }
        }
    }
}
```
Сначала **`"AddonName.FileName"`** — желаемая звуковая строка, которая будет использоваться для ее запуска/излучения.

И последнее и самое важное: **`"sounds/FileName.vsnd"`** содержит относительный путь к звуковым файлам, **скомпилированным ValveSound**. Звук, который вы добавили на шаге 2, был `.mp3`, движок преобразует этот звук в `.vsnd` при компиляции/сборке файла **`.vsndevts`**.

Во всем блоке это единственные строки, которые вы хотите изменить при добавлении нового звука. По сути, это большая копипаста одного и того же блока, просто меняя эти две строки.

Конечно, вы можете изменить громкость/высоту своих звуков, поиграйте для этого с переменными оператора.

## Шаг 4. Выпускаем и проверяем компиляцию звука
Как только файл звуковых событий будет готов, вам нужно заставить игру скомпилировать его, прежде чем вызывать строку с помощью KV `"FireSound"` или любого варианта Lua `EmitSound()`.

Для этого зайдите в браузер ресурсов Workshop Tools вашего дополнения, введите имя вашего пользовательского звукового события и выполните полную перекомпиляцию + перезагрузку.

![img](/images/external/guIUd-4ce0b6f142.png)

Теперь, если вы зайдете в папку дополнений к игре, там должна быть папка звуков и звуковых событий, которая должна содержать скомпилированную `_c` версию файлов, созданных в папке содержимого.

![img](/images/external/guJ7J-00d69a1243.png)

Если это не так, снова зайдите в браузер ресурсов и вместо звукового события введите имя вашего звукового файла и щелкните его. Если он начнет воспроизводиться, значит, он скомпилирован правильно.
