# Начало работы

Итак, вы новичок в моддинге Dota 2? Не знаете, с чего, черт возьми, начать? Это руководство для тебя, будущего моддера Dota 2!

Примечание. «Аддон», «мод» и «пользовательская игра» являются синонимами в этом руководстве (и, вероятно, на всем веб-сайте).

## Аспекты моддинга Dota 2

[Workshop Tools Wiki Homepage](https://developer.valvesoftware.com/wiki/Dota_2_Workshop_Tools) хорошо справляется с разделением всех возможных аспектов моддинга Dota 2:

- **Дизайн уровней** - Использует инструмент под названием «Молот».
- **Сценарии** — подразделяются на редактирование KeyValue и сценарии Lua.
- **Моделирование** - Импорт ваших собственных моделей в аддон.
- **Звуки** - Импорт собственных звуков или редактирование существующих.
- **Частицы** – редактирование существующих частиц или создание собственных с помощью инструмента редактирования частиц (PET).
- **Панорама** — Создание собственного пользовательского интерфейса или изменение существующего пользовательского интерфейса Dota 2 с помощью скриптов Panorama.

## Шаг 0. Установка и запуск инструментов мастерской Dota 2

Вы не сможете создавать моды для Dota без инструментов Мастерской!

взято из [How to install the Dota 2 Workshop Tools](https://developer.valvesoftware.com/wiki/Dota_2_Workshop_Tools/Installing_and_Launching_Tools):
- Щелкните правой кнопкой мыши Dota 2 в Steam и выберите «Просмотреть загружаемый контент».
- Установите флажок в столбце «Установить» рядом с DLC «Dota 2 Workshop Tools».
- Нажмите «Закрыть». Начнется загрузка необходимого контента.
- Когда загрузка будет завершена, запустите Dota 2 в Steam и выберите «Запустить Dota 2 — Инструменты».

## Шаг 1. Создание нового аддона из шаблона

Чтобы начать с хорошего, вам нужно создать новое дополнение на основе шаблона. У вас есть два варианта на выбор:

### Вариант 1: Шаблон дополнения TypeScript

Содержит:

- Объявления типов API Dota 2, которые помогут вам с проверкой ошибок и автозаполнением вашего кода.
- Пример правил игры
- Пример возможности TypeScript
- Пример модификатора TypeScript
— Пример пользовательского интерфейса Panorama с TypeScript.
- Скрипт автоматической установки
- Библиотека последних таймеров

Этот шаблон содержит все, что вам нужно для создания модов с помощью TypeScript. Dota 2 использует Lua в качестве языка сценариев, поэтому этот шаблон включает инструменты для автоматического перевода TypeScript в Lua. Он обеспечивает основу для разработки дополнений, но кроме этого содержит лишь несколько небольших примеров. Он поставляется с автоматической настройкой контроля версий git «из коробки».

Чтобы начать работу с шаблоном TypeScript, см. [The template GitHub page](https://github.com/ModDota/TypeScriptAddonTemplate) и [TypeScript introduction](scripting/Typescript/typescript-introduction.md) для ознакомления с шаблоном и инструкциями по установке.

### Вариант 2: Шаблон Barebones Lua

Содержит:

- Некоторые правила игры и настройки по умолчанию, которые вы можете легко настроить.
- Пример способностей Lua
- Примеры модификаторов Lua
- Некоторые старые библиотеки, такие как `animations`, `physics`, `projectiles` и `timers`.

Вы можете начать работу с шаблона Barebones, который является созданной сообществом альтернативой стандартным шаблонам дополнений Valve (например, Holdout). Это ссылка на обновленные Barebones: https://github.com/DarkoniusXNG/barebones<br />
После загрузки его в виде zip-архива вы хотите перейти к `.../Steam/SteamApps/dota 2 beta/` и объединить папки `game` и `content` из .zip в эту папку /dota 2 beta/ (в которой уже должны быть папки с именами `game` и `content`).
Затем запустите инструменты мастерской (или перезапустите их, если они уже открыты) и дважды щелкните новое дополнение. Установите его как аддон по умолчанию. Затем перейдите в Hammer -> Файл -> Открыть -> `template_map.vmap` -> Нажмите F9, чтобы начать создание карты. После того, как Хаммер завершит создание вашей карты, ваша собственная игра автоматически загрузится в Dota.

## Шаг 2. Создание карты в Hammer

<StaticVideo path="/videos/YearlyDismalHuemul.mp4" />

(Спасибо DarkMio за этот gfy.)

Hammer — это инструмент, который вы используете для создания миров для вашей собственной игры. Я настоятельно рекомендую вам сначала начать создавать что-то в Hammer, а не сразу погружаться в сценарии или другой аспект. У вас могут быть самые сложные сценарии в мастерской, но как люди будут получать удовольствие от вашей игры, если не существует мира, в котором они могли бы играть?

Как только вы дойдете до того, что для вашей карты будет заблокирован черновой макет, вероятно, можно будет безопасно перейти к написанию сценариев. Вы не хотите тратить слишком много времени на детализацию того, что, как вы понимаете, необходимо изменить, как только вы войдете в суть своего режима.
[The wiki page on Hammer](https://developer.valvesoftware.com/wiki/Dota_2_Workshop_Tools/Level_Design) хорошо знакомит вас с Hammer. Я бы рекомендовал вам начать с раздела [Tile editor](https://developer.valvesoftware.com/wiki/Dota_2_Workshop_Tools/Level_Design/Tile_Editor_Basics).

BMD подготовила несколько неплохих обучающих видеороликов по Hammer для начинающих:

- [Part 1: Tile Editor](https://www.youtube.com/watch?v=GMvmdnNM6Sc)
- [Part 2: Mesh Basics](https://www.youtube.com/watch?v=grLUv2hUDRY)
- [Part 3: Entity Basics](https://www.youtube.com/watch?v=ln3ep-k__dk)

Сценарии — следующая по важности часть вашего аддона. Он разделен на сценарии Lua и сценарии KeyValue. Я собираюсь перенаправить вас на [Noya's Beginner Scripting Guide](scripting-introduction.md), так как там содержится по сути та же информация, что и в этом разделе.
Теперь я буду говорить коротко и по делу. Я уже предоставил вам массу информации, чтобы вы могли начать углубляться в моддинг Dota 2! Если вы хорошо разбираетесь в картографии Hammer и сценариях Lua и KeyValue, это поможет создавать успешные и увлекательные пользовательские игры Dota 2.
