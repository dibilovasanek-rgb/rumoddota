четания клавиш

## Введение

В недавнем обновлении (20 июля) Valve добавила поддержку пользовательских сочетаний клавиш. То есть вы можете привязать клавиши для запуска специальной команды.

Используемая техника заимствована из rpg_example.

Хотя этот метод не обязательно ограничивается панорамой, в этом уроке основное внимание будет уделено их использованию в панораме.

## Настраивать
Начните с добавления пары строк в файл `addoninfo.txt`, расположенный в `/game/<your addon>/addoninfo.txt`.
```
"AddonInfo"
{
  "TeamCount" "10"
  "maps"      "your_map"
  "IsPlayable"  "1"
  "your_map"
  {
          "MaxPlayers"                    "10"
  }
  "Default_Keys"
    {
        "01"
        {
            "Key"       "S"
            "Command"   "CustomGameExecuteAbility1"
            "Name"      "Execute Ability 1"
        }
        "02"
        {
            "Key"       "Z"
            "Command"   "+CustomGameTestButton"
            "Name"      "Example"
        }
    }
}
```
Важными частями, конечно же, являются то, что определено в `"Default_Keys"`.

`"Key"`
это ключ, который вы хотите связать, используйте здесь заглавные буквы

`"Command"`
это команда для запуска, убедитесь, что имя команды уникально.  
Префикс команды определяет, когда сработает команда.

`"Name"`
Имя команды, используемой в целях отладки.

#### Префиксы команд

| Префикс | Пример | Описание |
| ----------- | ---------- | --------------------------------------- |
| _(ничего)_ | _команда_ | Команда сработает при нажатии и отпускании |
| ***+** | _+команда_ | Триггер при нажатии клавиши (используется для обычного нажатия клавиши) |
| **-** | _-команда_ | Команда сработает при отпускании клавиши |

Префиксы не блокируют запуск команды только в этом событии. Но это хорошая ссылка на то, что вы хотите, чтобы привязка клавиш делала.
## Панорама

Перехватить команды привязки клавиш в Panorama легко:
```
js
function OnExecuteAbility1ButtonPressed() {
  $.Msg("'S' Pressed or Released");
}

function OnTestButtonPressed() {
  $.Msg("'Z' Pressed");
}

function OnTestButtonReleased() {
  $.Msg("'Z' Released");
}

(function () {
  Game.AddCommand('CustomGameExecuteAbility1', OnExecuteAbility1ButtonPressed, '', 0);
  Game.AddCommand('+CustomGameTestButton', OnTestButtonPressed, '', 0);
  Game.AddCommand('-CustomGameTestButton', OnTestButtonReleased, '', 0);
})();
```
Обратите внимание, как снова используются префиксы. Несмотря на то, что мы определили запуск `CustomGameTestButton` только при нажатии клавиши, мы также можем легко перехватить событие выпуска в нашем JS.
