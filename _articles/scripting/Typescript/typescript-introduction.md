# Машинопись Введение

Typescript — это мощный инструмент, который мы можем использовать, чтобы улучшить нашу способность правильно писать сценарии для файлов Dota 2. Используя tstl (Typescript-to-Lua), он автоматически генерирует файл Lua для игры, который будет использоваться для каждого файла, над которым вы работаете — этот процесс полностью автоматический с момента его запуска.

Typescript более строгий по сравнению с Lua, будет использовать типы для реализации определенных функций и немедленно предупредит вас, если вы сделаете что-то, что не имеет для него смысла, и будет показывать ошибку, пока вы ее не исправите. Например, выполнение `GetStrength()` для способности не имеет смысла и приведет к появлению сообщения об ошибке.

Typescript может хорошо работать с большинством редакторов, использующих плагины, однако рекомендуется использовать [VSCode](https://code.visualstudio.com/), поскольку он имеет встроенную поддержку Typescript и является очень мощным редактором.

## Плюсы и минусы использования Typescript
**Плюсы:**

- Обеспечивает соблюдение типов, предотвращает использование ненужных функций.
— Typescript гораздо больше похож на большинство языков, таких как C#, Java, Javascript и C (по сравнению с Lua).
- Автозаполнение, при котором отображаются только функции API, соответствующие вызываемому типу.
- Экономит массу времени за счет немедленного обнаружения логических ошибок в коде, вместо того, чтобы искать их в игре (иногда в крайних случаях, которые не могут быть обнаружены во время локального тестирования).
- Потрясающая поддержка машинописного текста в Интернете (например, Stack Overflow) для решения распространенных вопросов по машинописному тексту.
- Сам Typescript имеет очень мощные встроенные функции и типы, такие как наборы, карты и функции массивов. Кроме того, он поддерживает наследование классов и типов.
— Typescript используется как для Lua, так и для Javascript, поэтому вам никогда не придется переключаться между языками сценариев; Typescript преобразует его на нужный вам язык.
— Автозаполнение различных аргументов в API, например встроенного списка событий.
- Встроенные перечисления и интерфейсы, позволяющие чрезвычайно быстро и легко найти определенное значение на основе Dota.
- Очень легко обновлять новые API, когда Valve (со временем) выпустит новые функции.
- Создает символическую ссылку на вашу папку Dota 2 в рамках установки, поэтому вы можете легко интегрировать свои изменения в GitHub, если захотите.

**Минусы:**

- Первая настройка занимает некоторое время.
- Некоторые редкие типы могут быть неправильными. При необходимости их можно обновить вручную.
- Иногда требуется дополнительная настройка для конкретной игровой логики, такой как интерфейсы, типы и приведения типов (это опять-таки связано с природой типизированного языка).
- Не очень удобно интегрировать в текущие проекты, хотя все равно может работать.
- Ссылаться на код или руководства, написанные на Lua, в Typescript может быть непросто из-за различий в работе этих языков.

## Настройка TypeScript

:::info
Это руководство предполагает, что вы используете Windows. Если у вас другая операционная система, обратитесь к нам в разделе TypeScript в [Telegram-канале](https://t.me/+4wTdvuzBPzUxOTgy).
:::

First, since Typescript uses Node.js, it must be installed on your computer. You can download NodeJS from [here](https://nodejs.org/en/). Simply choose the recommended version, which is the latest stable version. Download and install it with its default configuration.

Next, navigate to the [Typescript template](https://github.com/ModDota/TypeScriptAddonTemplate). This template has most of the files of a new addon configured for you, along with Typescript support.
There are two versions to use the template:

1. Without GitHub: if you're not planning to put your code in GitHub, clone the above template. See below for explanation how.

2. С GitHub: если вы планируете разместить свой код на GitHub, нажмите кнопку ![Use this template](/images/typescript-tutorial/templateButton.png), расположенную в правом верхнем углу страницы github. Это создаст новый репозиторий GitHub, который будет использовать шаблон под вашим именем. Введите имя и описание репозитория, а также укажите, является ли он общедоступным или частным. Вы можете оставить флажок «Включить все ветки» снятым, а затем нажать «Создать репозиторий на основе шаблона». Когда новый репозиторий будет создан, клонируйте его. См. ниже объяснение того, как это сделать. Тем, кто не знаком с github, я рекомендую использовать графический интерфейс Github, например [Github Desktop](https://desktop.github.com/).

Клонирование репозитория означает создание его копии на вашем компьютере. Это можно сделать, нажав «Код», затем «Загрузить Zip», как показано здесь:

![Cloning from Github](/images/typescript-tutorial/cloneRepo.png)

Затем вы можете извлечь ZIP-архив куда угодно. Однако НЕ помещайте его в папку Dota 2. Например, я поместил его на свой рабочий стол в папку «Пользовательские игры Dota 2». Извлеченная папка называется `TypeScriptAddonTemplate-master`, поэтому просто переименуйте ее, чтобы более правильно отразить название вашей пользовательской игры. Для этого урока я назвал его `typescript-example`.

## Создание аддона на основе Typescript в Dota

Теперь, когда у нас есть файлы на нашем компьютере, мы можем очень быстро настроить новую аддонную игру. Прежде чем это сделать, осталось сделать несколько шагов:
- Зайдите в свою папку, в моем случае `typescript-example`.
- Откройте `package.json` в любом текстовом редакторе. Вы заметите, что поле `name` представляет собой пустую строку. Добавьте название своей пользовательской игры. Например, я назвал его `typescript_tutorial`. Поле должно выглядеть так:
```
"name": "typescript_tutorial",
```
Сохраните и закройте файл.

:::информация
Убедитесь, что внутри папки `game/dota_addons` и `content/dota_addons` папки с игрой Dota 2 нет папки с таким именем. В процессе установки эти папки будут созданы для вас. Если папки существуют, сначала удалите их или измените имя в `package.json` на другое.
:::

- Находясь в папке с файлом `package.json`, который вы только что отредактировали, щелкните адресную строку, чтобы путь к вашей папке стал выделенным и доступным для редактирования в виде текста. Это должно выглядеть так:

![Click on path](/images/typescript-tutorial/clickAddressBar.png)
- Пока путь выделен, удалите текст и вместо этого введите «cmd» и нажмите Enter. Откроется командная оболочка с путем к папке, показанным прямо перед курсором ввода.

- Введите `npm install` и нажмите Enter. Вы увидите полосу загрузки, заполнение которой может занять около минуты. Если все прошло успешно, вы увидите, что рядом с папками `game` и `content` теперь есть значок «ярлыка». Теперь они связаны с вашей папкой Dota 2. Папка `typescript_tutorial` теперь существует как для `game/dota_addons/`, так и для `content/dota_addons` в вашей папке Dota 2.

:::информация
Папки с символическими ссылками представляют собой копии друг друга, где любое действие, выполненное с одной папкой, также применяется к другой папке. Поэтому вы можете просто работать с удобно расположенной папкой (в моем примере `Desktop/Dota 2 custom games/typescript-example`), и она автоматически применится и к папке Steam Dota 2.
:::

## Структура дополнения Typescript

Большая часть структуры Typescript идентична стандартному дополнению Dota, например, папка `scripts/npc/`.
Обратите внимание на папку `src` в корне проекта. Здесь вы создаете файлы Typescript и работаете над ними. При компиляции полученные файлы Lua помещаются в соответствующие места, например `/game/scripts/vscripts/` для файлов, созданных из `/src/vscripts/`. Вы можете добавить дополнительные папки внутри этих папок, что сохранит ту же маршрутизацию в выходном месте.

Вы можете изменить структуру папок внутри аддона. Однако вам может потребоваться настроить пути вывода в соответствии с этими изменениями. Некоторые изменения могут нарушить работу мода, поскольку Dota ожидает установки определенной структуры (например, `game/scripts/vscripts`).

:::информация
В `src` вы также найдете папку `common`. Эта папка чрезвычайно полезна для хранения объявлений интерфейса, которые используются игровой логикой и панорамой, таких как события и сетевые таблицы, а также других пользовательских объявлений, таких как перечисления. **Эта папка должна содержать только файлы d.ts**.
:::

Существует несколько дополнительных файлов и папок, отвечающих за идентификацию Typescript и работу с API Dota 2, а также в пользовательской игре в целом.
Большую часть этих файлов можно оставить нетронутыми. Большинство этих файлов расположены в папке `/src/vscripts/`:

- `tsconfig.json`: настраивает работу Typescript в Lua-части проекта. Файл того же типа существует в папке `/src/panorama/` для конфигурации JavaScript для панорамы.

- `vscripts/lib/dota_ts_adapter.ts`: отвечает за регистрацию различных распространенных классов, таких как способности, предметы и модификаторы.
- `vscripts/lib/tstl-utils.ts`: отвечает за перевод машинописного текста в Lua.
- `vscripts/lib/timers.lua` и `vscripts/lib/timers.d.ts`: общая библиотека таймеров уже включена по умолчанию в ее форму Lua, а timers.d.ts включает интерфейс, позволяющий использовать библиотеку таймеров в Typescript.

## Обновление вашего аддона

Время от времени Valve выпускает новый API или изменения в существующем API, обычно во время мероприятий и крупных патчей. Ваш проект Typescript не будет автоматически адаптироваться к этим изменениям, поскольку их сначала необходимо сохранить и напечатать, что обычно делает сообщество, поддерживающее шаблон Typescript. Однако когда будет объявлено о новом обновлении Typescript для Dota 2, вы сможете легко обновить свой проект. Есть два способа сделать это:

- Использование терминала VSCode: если вы выбрали редактор VSCode и в нем загружена папка вашего проекта, нажмите «Терминал» -> «Новый терминал». Откроется новый терминал. Введите `npm update` и нажмите Enter.

- Использование cmd: откройте cmd из корневого каталога вашего проекта (в моем примере `Desktop/Dota 2 custom games/typescript-example`), затем введите `npm update` и нажмите Enter.
Проект автоматически обновится до последней версии.

## Активация Наблюдателя

Чтобы ваши файлы могли скомпилироваться и иметь скомпилированные эквиваленты Lua или javascript, необходимо активировать наблюдатель. Наблюдатель отслеживает все изменения, внесенные в ваши файлы в проекте, и немедленно создает эквивалент Lua или JavaScript, при условии, что файл скомпилирован без ошибок. Активировать наблюдателя можно тремя способами:

- Использование терминала VSCode: если вы используете VSCode и в нем загружена папка вашего проекта, нажмите «Терминал» -> «Выполнить задачу сборки». Альтернативно вы можете использовать для этого горячую клавишу `Ctrl+Shift+B` по умолчанию.

- Использование cmd: откройте cmd из корневого каталога вашего проекта (в моем примере `Desktop/Dota 2 custom games/typescript-example`), затем введите `npm run dev` и нажмите Enter.

- Другие редакторы: в зависимости от редактора у него может быть собственный метод для вызова команды «Выполнить задачу сборки»; дополнительную информацию можно найти в документации редактора.

## Нормализованные типы

При выгрузке перечислений из API Dota они имеют несколько предопределенных типов. С некоторыми из этих типов не очень удобно работать, поэтому вместо них мы используем нормализованные типы. Эти нормализованные типы слегка меняют перечисления, и их цель — повысить читаемость вашего кода. Шаблон поставляется с уже активированными нормализованными типами.

## Интегрированные примеры

На момент написания этого руководства шаблон Typescript содержал несколько примеров, показывающих, как игровая логика реализуется в Typescript. Я рекомендую сохранить эти файлы для справки, пока вы не освоитесь с Typescript.

Примеры:

- В `src/vscripts/abilities/heroes/meepo/earthbind_ts_example.ts`: пример пользовательской способности Meepo Earthbind.
- В `src/vscripts/modifiers/modifier_panic.ts`: специальный модификатор, который ограничивает команды и приказывает родителю периодически перемещаться в случайную позицию рядом с ним.
- В `src/vscripts/GameMode.ts`: примеры логики игрового режима, такие как установка максимального количества игроков для каждой команды равным 3. Здесь также показаны примеры таймера и прослушивания событий.
- В `src/panorama/hud.ts`: пример Panorama для подписки и отправки событий.

Вы можете увидеть, как примеры применяются в вашем аддоне:

- К каждому выбранному вами герою будет добавлена специальная способность Meepo's Earthbind.
- В центре экрана отображается панель приветствия. Нажатие на кнопку закрытия в нем удалит панель и применит модификатор паники на несколько секунд.
