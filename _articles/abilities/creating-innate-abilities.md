здание врожденных (доступно с 1 уровня) способностей.

Эта статья поможет вам создать способность, которая сразу же будет доступна данному герою, например, Stone Remnant Earth Spirit.
В этом руководстве предполагается, что у вас уже есть способность, настроенная для героя.

## Способности Lua

Способности Lua могут определять метод `Spawn`, который вызывается движком при создании способности.
```
lua
my_innate_ability = my_innate_ability or {}
function my_innate_ability:Spawn()
    if IsServer() then
        self:SetLevel(1)
    end
end
```

## Управляемые данными и встроенные возможности

План таков:

1. Подпишитесь на событие появления героя.
2. Определите, есть ли у появившегося героя особая способность.
3. Повышайте уровень

Хорошо. Поскольку точкой входа в каждый мод является файл `addon_game_mode.lua`, перейдите туда и найдите `function Activate()`.
Активация — это функция, вызываемая в самом начале нашей пользовательской игры, когда все игроки загрузились.
Мы можем подписаться на события, используя `ListenToGameEvent`.

Поместите следующий код в функцию `Activate`:
```
lua
ListenToGameEvent('npc_spawned', function(event)
    HandleNpcSpawned(event.entindex)
end, nil)
```
Этот код подписывается на событие `npc_spawned`, а затем вызывает функцию HandleNpcSpawned (мы создадим ее позже) с порожденным индексом сущности.
Этот индекс сущности предоставляется нам в таблице событий при запуске события.

Давайте создадим функцию `HandleNpcSpawned`, поместим ее в тот же файл чуть ниже `Activate`:
```
lua
function HandleNpcSpawned(entityIndex)
    local entity = EntIndexToHScript(entityIndex)
    local innateAbilityName = "my_innate_ability"

    if entity:IsRealHero() and entity:HasAbility(innateAbilityName) then
        entity:FindAbilityByName(innateAbilityName):SetLevel(1)
    end
end
```
Давайте пройдемся здесь построчно. После определения функции, которая принимает наш параметр objectIndex, мы определяем переменную, которая содержит фактическую сущность.
Мы превращаем индекс объекта в реальный объект, используя `EntIndexToHScript`. Теперь мы можем вызывать методы нашей реальной сущности.
Сначала мы объявляем имя нашей врожденной способности, чтобы ее было проще использовать.
Затем мы создаем условие, в котором проверяем, что наша сущность действительно является героем и обладает такой способностью.
Если все условия выполняются, мы получаем дескриптор этой способности и сразу же устанавливаем для нее уровень 1.

Вот и все! Теперь все герои, у которых есть `my_innate_ability`, будут автоматически повышать его уровень при появлении.
