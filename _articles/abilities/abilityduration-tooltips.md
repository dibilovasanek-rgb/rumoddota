должительности способностей

**TL;DR:**abilityDuration — довольно бесполезное значение ключа, потому что тот, кто его кодировал, забыл сделать автоматическую всплывающую подсказку, как в случае с `AbilityDamage`. Используйте «duration»abilityValue и вместо этого соедините его с lua.

Представьте, что вы хотите, чтобы способность применяла модификатор на несколько секунд, длительность которого меняется с уровнем.

Вы можете попасться в ловушку и сделать это:
```
"AbilityDuration" "3 2 2"
```
Затем ваш модификатор ссылается на %AbilityDuration в ключе-модификаторе «Продолжительность». Пока все в порядке.

Но если вы хотите указать, что ваша способность действует в течение указанного периода времени, параметр «AbilityDuration» не генерирует всплывающую подсказку **"DURATION:"** сама по себе, поэтому у вас есть 3 варианта:

**Вариант 1.** Напишите «Последние 3 секунды на уровне 1, а затем 2 на уровнях 2 и 3» в `_Description`.

Это плохо по причинам, объясненным ранее.

**Вариант 2\*.** В дополнение к `AbilityDuration` укажите «duration»abilityValue и синхронизируйте оба значения.
Неоптимальное, но достойное решение, поскольку оно позволяет использовать способность:GetAbilityDuration(), которая принимает значение изabilityDuration.

**Вариант 3.** Удалите «AbilityDuration», оставив только «AbilityValue». Лучший способ, насколько я могу судить.
```
"AbilityValues"
{
  "duration" "3 2 2"
}
```
А затем, если необходимо, сделайте это в сценарии Lua.
```
lua
function HowToTooltip(event)
   local ability = event.ability
   local duration = ability:GetLevelSpecialValueFor("duration", (ability:GetLevel() - 1))
   local damage = ability:GetAbilityDamage()
end
```
Имеет одинаковые результаты и работает для любого сценария.
