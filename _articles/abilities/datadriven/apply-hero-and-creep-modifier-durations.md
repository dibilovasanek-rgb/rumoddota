Я придумал этот метод после того, как Критт показал нам, что вы можете напрямую добавить значение ключа `"Duration"` к блоку `"ApplyModifier"` и использовать блок `"Target"` без радиуса (по умолчанию равно 0).

По сути, злоупотребляя системой, управляемой данными, мы можем сделать это при любом событии:
```
"ApplyModifier"
{
    "ModifierName"	"modifier_name"
    "Target"
    {
        "Center"	"TARGET"
        "Types"  "DOTA_UNIT_TARGET_HERO"
    }
    "Duration"	"%hero_duration"
}

"ApplyModifier"
{
    "ModifierName"	"modifier_name"
    "Target"
    {
        "Center"	"TARGET"
        "Types"  "DOTA_UNIT_TARGET_BASIC"
    }
    "Duration"	"%creep_duration"
}
```
modifier_name — любой модификатор **без «Продолжительность»**, указанный непосредственно в его блоке.

Надеемся, что благодаря этому многие случаи, когда нужно применять разную продолжительность к герою и крипам, станут проще читать и дорабатывать. До сих пор я использовал Lua для определения различной продолжительности, но после знакомства с этой системой она стала намного лучше.
