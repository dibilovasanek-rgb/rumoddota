# Преобразования

В этом уроке я жульничаю и не объясняю, как создать способность Lua. Если вы хотите увидеть полный пример кода [click here!](https://gitlab.com/DrTeaSpoon/Dota2Overflow/tree/master/game/dota_addons/dota2overflow/scripts/vscripts/lua_abilities/ultimates/metamorph)

Теперь мы сосредоточимся на модификаторе lua. Хотя мы можем выполнять преобразования и прочее в аналоге, управляемом данными, не хватает вычислений, которые заставили бы эти вещи работать лучше.
Первым вопросом является дальность и тип атаки. Мы предполагаем, что наша специальная способность имеет особую ценность для `attack_range` и предназначена для трансформации существа ближнего боя. В этом примере мы используем Рошана, поэтому, чтобы дальность атаки соответствовала оригиналу, мы установили его на `128`.
```
lua
function transformation_mod:OnCreated( kv )
    if IsServer() then
        self.AttackBonus = (self:GetParent():GetAttackRange() - self:GetAbility():GetSpecialValueFor("attack_range")) * -1
        --We get original attack range and subtract away the wanted attack range, then negate the result.
        --YAY Math!
        self.OriginalAtkCap = self:GetParent():GetAttackCapability()
        --Save original so we can set it back.
        self:GetParent():SetAttackCapability(DOTA_UNIT_CAP_MELEE_ATTACK)
    end
end
```
Теперь нам нужно сделать так, чтобы при потере этого модификатора мы изменили тип атаки обратно на исходный.
```
lua
function transformation_mod:OnDestroy()
    if IsServer() then
        self:GetParent():SetAttackCapability(self.OriginalAtkCap)
    end
end
```
Сюда следует отнести то, на что, по нашему мнению, должна повлиять трансформация, это некоторые общие моменты.
```
lua
function transformation_mod:DeclareFunctions()
    local funcs = {
        MODIFIER_PROPERTY_MODEL_CHANGE,
        MODIFIER_PROPERTY_MODEL_SCALE,
        MODIFIER_PROPERTY_ATTACK_RANGE_BONUS
    }
    return funcs
end
```
Теперь нам нужно реализовать эти функции. Первый — для модели, второй — для дальности атаки и последний — для масштаба.
```
lua
function transformation_mod:GetModifierModelChange() return "models/creeps/roshan/roshan.vmdl" end
function transformation_mod:GetModifierAttackRangeBonus() return self.AttackBonus end
function transformation_mod:GetModifierModelScale() return self:GetAbility():GetLevel()*0.5 end
```
Последние проблемы — использование способностей при иммунитете и правильное дублирование модификатора иллюзий.
```
lua
function metamorphosis_mod:GetAttributes() return MODIFIER_ATTRIBUTE_IGNORE_INVULNERABLE end
function metamorphosis_mod:AllowIllusionDuplicate() return true end
```
Вот и все. Вы можете добавить эффекты частиц и/или анимацию. Хотя, обратите внимание, есть некоторые проблемы с анимацией некоторых героев. Например, анимация смерти Phantom Lancer заставляет модель игрока исчезнуть, поэтому я советую быть осторожным с выбранной анимацией.
