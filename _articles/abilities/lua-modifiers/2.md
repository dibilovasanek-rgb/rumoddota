# Сфера Линкена и сфера лотоса

Когда вы пишете свои целевые способности Lua, у вас могла возникнуть проблема с неработающей защитой от таких заклинаний. Сфера Линкена и Сфера Лотоса.
Чтобы эти элементы повлияли на вашу новую крутую способность, вам нужно всего лишь добавить эту строку в свой код:
```
lua
if hTarget:TriggerSpellAbsorb( self ) then return end
`
```
hTarget` в этом примере предполагается целевым устройством. `self` — это ваша способность. Он используется такими способностями, как сфера лотоса, чтобы знать, какое заклинание отправить обратно. `hTarget:TriggerSpellAbsorb( self )` возвращает true, только если у игрока есть Сфера Линкена или какой-либо специальный элемент, закодированный для выполнения аналогичной функции.
В случае Lotus Orb та же строка запускает Lotus Orb, но всегда возвращает false.
Теперь, чтобы создать свои собственные эффекты, подобные Lotus/Linken, вот два объявления функций:
```
lua
function my_modifier:DeclareFunctions()
    local funcs = {
        MODIFIER_PROPERTY_REFLECT_SPELL, --Lotus Orb trigger.
        MODIFIER_PROPERTY_ABSORB_SPELL --Linken's Sphere trigger.
    }
    return funcs
end

function my_modifier:GetReflectSpell(keys)
  print("you cast your spell on me!")
end

function my_modifier:GetAbsorbSpell(keys)
  if something then
      print("counter spell!")
       return 1 --conditions were met, lets return 1 to block the spell.
    end
    return false --do nothing and let the spell through.
end
```
В случае со сферой Linken код в значительной степени проверяет время восстановления исходной способности, а если время восстановления не установлено, воспроизводите эффект, возвращаете 1.
```
lua
function my_modifier:GetAbsorbSpell(keys)
    local hAbility = self:GetAbility()
    if hAbility:IsCooldownReady() then
    --your cool effect here.
    hAbility:StartCooldown(hAbility:GetCooldown(hAbility:GetLevel()))
    return 1
    end
    return false
end
```
Просто, правда? Lotus Orb немного сложнее, и даже моя версия не полностью проверена на наличие ошибок, но до сих пор она работала отлично.
```
lua
function my_modifier:GetReflectSpell(keys)
    if self.stored ~= nil then
        self.stored:RemoveSelf() --we make sure to remove previous spell.
    end
    local hCaster = self:GetParent()
    local hAbility = hCaster:AddAbility(kv.ability:GetAbilityName())
    hAbility:SetStolen(true) --just to be safe with some interactions.
    hAbility:SetHidden(true) --hide the ability.
    hAbility:SetLevel(kv.ability:GetLevel()) --same level of ability as the origin.
    hCaster:SetCursorCastTarget(kv.ability:GetCaster()) --lets send this spell back.
    hAbility:OnSpellStart() --cast the spell.
    self.stored = hAbility --store the spell reference for future use.
end
```
Причина, по которой мы удаляем сохраненное заклинание при следующем срабатывании, заключается в том, чтобы убедиться в отсутствии нулевой ссылки. Например, если модификатор, созданный заклинанием, попытается получить доступ к исходному заклинанию, и если бы мы удалили его сразу после применения, игра выдала бы сообщение об ошибке.
Несколько идей, как вы могли бы использовать все, что узнали здесь:
-Создайте комбинацию лотоса и звенящей сферы. (блокировать и отражать)
-Пассивный, отражающий каждое третье заклинание.
-Пассивный, который блокирует заклинание и дает вам использованную на него ману.
-Моргайте и отделяйте снаряды, когда против вас наложено заклинание.

Вот небольшой фрагмент кода, который поможет вам начать работу с миганием:
```
lua
function my_modifier:Blink(hTarget, vPoint, nMaxBlink, nClamp)
    local vOrigin = hTarget:GetAbsOrigin() --Our units's location
    ProjectileManager:ProjectileDodge(hTarget)  --We disjoint disjointable incoming projectiles.
    ParticleManager:CreateParticle("particles/items_fx/blink_dagger_start.vpcf", PATTACH_ABSORIGIN, hTarget) --Create particle effect at our caster.
    hTarget:EmitSound("DOTA_Item.BlinkDagger.Activate") --Emit sound for the blink
    local vDiff = vPoint - vOrigin --Difference between the points
    if vDiff:Length2D() > nMaxBlink then  --Check caster is over reaching.
        vPoint = vOrigin + (vPoint - vOrigin):Normalized() * nClamp -- Recalculation of the target point.
    end
    hTarget:SetAbsOrigin(vPoint) --We move the caster instantly to the location
    FindClearSpaceForUnit(hTarget, vPoint, false) --This makes sure our caster does not get stuck
    ParticleManager:CreateParticle("particles/items_fx/blink_dagger_end.vpcf", PATTACH_ABSORIGIN, hTarget) --Create particle effect at our caster.
end
