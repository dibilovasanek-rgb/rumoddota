# Чарующие деревья

Без дальнейших проволочек, давайте приступим! `npc_abilities_custom.txt` запись о наших возможностях.
```
"enchant_tree_lua"
{
    // These are required for this to work
    "BaseClass"             "ability_lua"
    "ScriptFile"                    "lua_abilities/enchant_tree/ability.lua" //set your script file path in 'vscripts' folder
    "AbilityBehavior"               "DOTA_ABILITY_BEHAVIOR_UNIT_TARGET"
    "AbilityUnitTargetTeam"         "DOTA_UNIT_TARGET_TEAM_CUSTOM"
    "AbilityUnitTargetType"         "DOTA_UNIT_TARGET_TREE"
    "AbilityDuration"               "10.0" //well, technically optional.
    // Optional stuff
    "AbilityTextureName"            "enchant_tree_lua"
    "AbilityCastPoint"              "0.1"
    "AbilityCooldown"               "5.0"
    "AbilityManaCost"               "100"
    "AbilityCastRange"              "400"
}
```
Это ваш базовый старт для навыков Lua.
```
lua
if enchant_tree_lua == nil then
    enchant_tree_lua = class({})
end
LinkLuaModifier( "enchant_tree_lua_mod", "lua_abilities/enchant_tree/modifier.lua", LUA_MODIFIER_MOTION_NONE )
```
Здесь происходит волшебство. `CreateModifierThinker` создает своего рода невидимый юнит с прикрепленным к нему модификатором.
```
lua
function enchant_tree_lua:OnSpellStart()
    CreateModifierThinker( self:GetCaster(), self, "enchant_tree_lua_mod", { duration = self:GetDuration() }, self:GetCursorPosition(), self:GetCaster():GetTeamNumber(), true )
end
```
Теперь для следующего волшебства нам нужно настроить наш крутой модификатор. В этом примере путь к файлу будет `vscripts/lua_abilities/enchant_tree/modifier.lua`.
Каждое «зачарование дерева» состоит из двух основных частей. Сначала нужно убедиться, что рядом есть дерево. Из-за ограничений движка с деревьями сложно взаимодействовать. В нашем решении мы просто каждые полсекунды запрашиваем у Gridnav, есть ли деревья на очень маленькой территории в месте расположения нашего мыслительного модуля.
Последняя часть — это незначительная оптимизация, которая может стать лишней, но на момент ее разработки этого не было. Была проблема, из-за которой мыслитель оставался на карте некоторое время после уничтожения модификатора.
```
lua
if enchant_tree_lua_mod == nil then
    enchant_tree_lua_mod = class({})
end
function enchant_tree_lua_mod:OnCreated( kv )
    if IsServer() then
        self:StartIntervalThink(0.5)
    end
end
function enchant_tree_lua_mod:OnIntervalThink()
    if IsServer() then
        if not GridNav:IsNearbyTree(self:GetParent():GetAbsOrigin(), 10, false) then
            self:Destroy()
        end
    end
end
function enchant_tree_lua_mod:OnDestroy()
    if IsServer() then
        UTIL_Remove( self:GetParent() )
    end
end
```
Теперь самое интересное. Что мы хотим сделать с этим модификатором.
Я решил использовать дерево сбора душ: если вражеский герой убит в радиусе (вам нужно добавить это к специальным значениям вашего `npc_abilities_custom.txt`), владелец заклинания крадет до 2 основных характеристик жертвы.
```
lua
function enchant_tree_lua_mod:DeclareFunctions()
    local funcs = {
        MODIFIER_EVENT_ON_HERO_KILLED
    }
    return funcs
end

function enchant_tree_lua_mod:OnHeroKilled(kv)
    if IsServer() then
        if kv.unit and kv.unit:GetTeam() ~= self:GetCaster():GetTeam() then
            if (self:GetParent():GetAbsOrigin() - kv.unit:GetAbsOrigin()):Length2D() <= self:GetAbility():GetSpecialValueFor("radius") then
                self:CollectSoul(kv.unit)
            end
        end
    end
end

function enchant_tree_lua_mod:CollectSoul(hTarget)
  local primary = hTarget:GetPrimaryAttribute()
  local val = hTarget:GetPrimaryStatValue()
  local n = math.max (0, math.min(2,val))
  if primary == 0 then
    self:GetCaster():ModifyStrength(n)
    hTarget:ModifyStrength(n*-1)
  elseif primary == 1 then
    self:GetCaster():ModifyAgility(n)
    hTarget:ModifyAgility(n*-1)
  else
    self:GetCaster():ModifyIntellect(n)
    hTarget:ModifyIntellect(n*-1)
  end
end
```
Для тех причудливых эффектов, которые дает железное дерево, вы можете добавить эти строки
```
lua
function enchant_tree_lua_mod:GetEffectName()
 return "particles/items_fx/ironwood_tree.vpcf"
end

function enchant_tree_lua_mod:GetEffectAttachType()
 return PATTACH_OVERHEAD_FOLLOW
end
```
